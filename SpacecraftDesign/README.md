# Spacecraft Design Tool - 宇宙飞船设计工具

这是一个独立的 Processing 草图，用于设计和调试宇宙飞船的外观。

## 功能特点

- 🎨 **实时预览**：实时显示飞船外观
- 🎛️ **参数调整**：通过滑块调整各种参数
- 📐 **可缩放**：调整预览缩放比例
- 📋 **代码生成**：一键输出可用的绘图代码

## ✅ 无需安装任何外部库

本工具使用纯 Processing 原生 GUI 组件，无需安装任何第三方库！

## 可调整参数

### 船体参数
- **bodyLength**: 船体长度 (5-30)
- **bodyWidth**: 船体宽度 (2-12)

### 机翼参数
- **wingAngle**: 机翼角度 (20-80°)
- **wingLength**: 机翼长度 (5-20)
- **wingWidth**: 机翼宽度 (2-8)

### 引擎参数
- **engineSize**: 引擎大小 (2-10)
- **flameLength**: 火焰长度 (3-15)
- **flameIntensity**: 火焰强度 (100-255)

### 特效参数
- **glowSize**: 发光尺寸 (8-25)
- **glowAlpha**: 发光透明度 (20-100)

## 使用方法

### 1. 运行草图

1. 在 Processing IDE 中打开 `SpacecraftDesign` 文件夹
2. 直接点击运行按钮（无需安装任何库）

### 2. 调整参数

- **拖动滑块**：左右拖动即可调整参数
- **重置按钮**：点击 "Reset Defaults" 恢复默认值
- **导出代码**：点击 "Print Code" 输出绘图代码

### 3. 导出代码

1. 调整满意后，点击 **"Print Code"** 按钮
2. 在 Processing 控制台查看生成的绘图代码
3. 复制代码到主程序使用

## 快捷键

- **P**: 打印绘图代码到控制台
- **R**: 恢复默认参数

## 界面说明

### 左侧控制面板
- 包含所有可调整参数的滑块
- "Reset Defaults" 按钮
- "Print Code" 按钮

### 右侧预览区域
- 网格背景用于参考比例
- 实时显示飞船预览
- 可调整预览缩放比例

### 右上角信息面板
- 显示当前参数值
- 操作提示

## 设计元素

飞船包含：
- ✅ 发光效果（多层半透明圆）
- ✅ 机翼（上下对称，可调角度）
- ✅ 主体形状（自定义多边形）
- ✅ 三层引擎火焰（渐变效果）

## 提示

- 调整参数时会实时更新预览
- 可以调整缩放比例查看不同大小的效果
- 生成的代码可直接复制到 `Spacecraft.pde` 的 `draw()` 方法中

## 文件说明

## 故障排除

### 滑块无法拖动
- 确保点击的是滑块区域（深色条）
- 鼠标需要按下并拖动

### 按钮点击无效
- 点击后可能需要稍等一下
- 确保点击的是按钮内部区域

### 文本显示异常
- Processing 会自动处理字体
- 如果显示有问题，可以尝试调整窗口大小
