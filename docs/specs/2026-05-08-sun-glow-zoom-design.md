# 太阳光晕移除与缩放调整

**日期**: 2026-05-08

**状态**: 已完成

## 1. 需求背景

用户希望：
1. 移除太阳的固定屏幕尺寸光晕效果
2. 调整相机缩放限制：下限更小（可放大更多），上限设限制（避免缩得太小）

## 2. 实施方案

### 变更 1: 移除太阳光晕

**文件**: `SolarSystem.pde`
**位置**: `drawSun()` 方法

**变更内容**:
- 删除了5层固定光晕循环（第65-68行）
- 保留太阳本体绘制

**变更前代码**:
```processing
noStroke();
for (int g = 5; g >= 1; g--) {
  fill(255, 200, 50, 15 + g * 5);
  ellipse(sx, sy, 20 + g * 15, 20 + g * 15);
}
```

**变更后**: 删除上述代码

### 变更 2: 调整缩放限制

**文件**: `Camera.pde`
**位置**: `handleMouseWheel()` 方法

**变更内容**:
- 最小缩放值: `1e-15` → `1e-18` (放大倍数提升1000倍)
- 最大缩放值: `1e-2` → `1e-1` (缩小倍数提升10倍)

**变更前**:
```processing
targetScale = constrainDouble(targetScale, 1e-15, 1e-2);
```

**变更后**:
```processing
targetScale = constrainDouble(targetScale, 1e-18, 1e-1);
```

## 3. 预期效果

- ✅ 太阳不再有固定的屏幕尺寸光晕
- ✅ 可以更大地放大查看细节（缩放下限更小）
- ✅ 保持合理的缩小范围（不会看到太多屏幕外太空）
